# 掘掘熊 DigBear 浏览器扩展

在网页上右键 →「用掘掘熊翻找这一页」，网页地址就交给桌面应用去翻找。
链接、图片、视频都可以直接对它们右键。

## 安装（Chrome / Edge）

1. 先安装桌面版掘掘熊（安装包会注册 `digbear://` 协议）。
2. 打开扩展管理页：
   - Chrome：`chrome://extensions`
   - Edge：`edge://extensions`
3. 打开右上角的「开发者模式」。
4. 点「加载已解压的扩展程序」，选择本目录 `apps/extension`。
5. 建议把扩展固定到工具栏，点图标就能翻找当前页。

## 原理

扩展只做一件事：把选中的网址拼成 `digbear://crawl?url=<编码后的网址>`，
交给系统协议处理程序 —— 也就是掘掘熊桌面应用。

桌面应用已经在运行时会复用同一个窗口（单实例），不会开出第二个。

## 没装桌面版？

点右键菜单时浏览器会提示「找不到处理程序」。
装好桌面版并重开浏览器即可；协议是安装时注册的，无需管理员权限。
