# 掘掘熊 DigBear v0.4.0（Windows 首个正式版）

输入一个网址，把网页里的图片、视频、音乐与字体收进本地文件夹。

掘掘熊（DigBear）是 [Crawl Bear（超级爬爬熊）](https://github.com/xw-meow/crawl-bear) 的
Windows 移植版，并在功能与体验上做了自己的扩展。上游为 macOS 版本，采用 MIT 许可证，
**技术分析与逐文件改动说明见 [PORTING.md](https://github.com/odin1024/DigBear/blob/main/PORTING.md)。**

## 下载

| 文件 | 说明 |
| --- | --- |
| `DigBear_0.4.0_x64-setup.exe` | **NSIS 安装包，推荐个人用户使用** |
| `DigBear_0.4.0_x64_zh-CN.msi` | MSI（简体中文），便于企业批量部署 |
| `DigBear_0.4.0_x64_en-US.msi` | MSI（英文） |
| `DigBear_extension_v0.4.0.zip` | 浏览器扩展（Chrome / Edge），需先装桌面版 |

校验值见同目录的 `SHA256SUMS`。

> **应用未做代码签名**，首次运行 Windows SmartScreen 会拦截，
> 点「更多信息 → 仍要运行」即可。

## 系统要求

- Windows 10 1809 及以上 / Windows 11（x64）
- [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)：
  Win11 自带，Win10 若缺失应用会提示安装
- FFmpeg 为可选依赖，**只有下载 HLS / DASH 流、或需要合并音视频时才用得上**
  （设置 → 扩展管理 → 一键安装，装的是应用私有副本，不污染系统 PATH）

## 这一版能做什么

**抓得全**
- 12 种采集来源：DOM、CSSOM、`performance` 资源计时、页面源码里的 HLS/DASH 清单……
- 同源 `<iframe>` 与开放模式 Shadow DOM 里的素材也会被收进来
- 补充了 `<track>`、`<object data>`、`<embed src>` 的资源发现
- YouTube 观看页会直接给出最高清的视频流（innertube 接口取 H.264 + AAC 音轨）

**用得顺**
- 多网址批量翻找队列，结果合并成一份清单
- 结果页可按类型过滤、只看大图、预览、导出 CSV / JSON
- 文件名模板支持 `{name} {site} {kind} {index} {date}`
- 一键「全收下」；下过的资源自动跳过
- 下载失败自动重试（指数退避，次数可调）
- 下载前检查目标盘剩余空间，不够时提前提示
- 系统托盘常驻 + 下载完成走 Windows 通知中心

**数据在你手里**
- 只读访问网页，不上传任何素材，没有遥测
- 登录信息只存在本机的 WebView 数据目录
- 设置页一键「恢复出厂设置」，回到刚装好的样子

**顺手多做的一些**
- 浏览器扩展：Chrome / Edge 里一键把当前页交给掘掘熊
- `digbear://` 深链：链接与脚本都能直接触发翻找
- 资源管理器文件夹右键菜单：扫描本地快捷方式与文本里的网址
- 单实例：重复唤起不会开出第二个窗口
- 独立「关于」页 + 公众号二维码反馈入口

## 已知限制

- 第三方追踪像素（无扩展名的 `<img>`）会被识别成图片，需要手动过滤
- `blob:` 流（MSE / 实时 HLS）仍抓不到，需要 CDP 网络层方案（见 ROADMAP）
- closed shadow DOM 抓不到
- 脚本在提取之后才设置的背景图抓不到
- 应用未签名，SmartScreen 会拦一次
